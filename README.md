# Test Driven Development und Behavior-driven Development

Dr.-Ing. Grigory Devadze

141 Folien für das zweitägige Seminar mit Python, pytest, unittest, Gherkin, behave, GitLab und Jenkins.

## Präsentation öffnen

**[Präsentation im Browser starten](https://grigory-consulting.github.io/python-tdd-bdd-slides/?scrollActivationWidth=false)**

Das Repository herunterladen und **`index.html` im Browser öffnen**. Die Datei enthält die Präsentation einschließlich Schriften, Diagrammen und Reveal.js. Zum Präsentieren sind keine Installation und keine Internetverbindung nötig; Quellenlinks benötigen Internetzugang.

| Taste | Funktion |
|---|---|
| Pfeil rechts / Leertaste | Nächste Einblendung oder Folie |
| Pfeil links | Zurück |
| `Esc` | Übersicht: Folien unter ihrem Kapitel anzeigen und direkt anklicken |
| `F` | Vollbild |
| `S` | Sprechernotizen |
